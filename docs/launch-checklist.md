# Launch checklist

## Completed backend and workflow checks

- [x] Confirm the wedding date, entry close, and draw time.
- [x] Confirm the GitHub Pages URL and project base path.
- [x] Create the private Google Sheet and install the Apps Script files.
- [x] Run **Wedding Draw > Setup Spreadsheet**.
- [x] Deploy the web app and connect its `/exec` URL.
- [x] Submit a clearly marked fake entry and verify server-authoritative pricing.
- [x] Verify the private Orders row and payment-instruction email.
- [x] Verify the Payment Received checkbox and summary calculations.
- [x] Confirm one Jar Entries row is created for every Included entry.
- [x] Create and count matching printable slips.
- [x] Verify the public counter exposes aggregate totals only.
- [x] Verify cancellation and refund statuses remove entries from the current draw.
- [x] Remove fake rows, slips, totals, and test emails.

## Visual and sharing checks

- [ ] Check the site and form at 1440px, 768px, 390px, and 320px wide.
- [ ] Preview the social share card on a phone.
- [ ] Share the live link with friends and family.

These checks remain open until they are completed manually. Do not mark them complete based only on a build or automated test.

## Before the recorded draw

Follow the [Physical draw runbook](draw-runbook.md) to reconcile payments, create the private snapshot, print and count every slip, and record the draw.
